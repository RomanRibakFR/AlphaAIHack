## 3. Данные

Модель обучена на **синтетических** заёмщиках. Структура профилей взята из открытых данных, денежные потоки и просрочки смоделированы. Реальные исходы и банковские данные не использовались. Тестовые компании в `mocks/companies/` вымышлены: совпадения ИНН, названий и ФИО с реальными случайны.

| Датасет | Что взято | Лицензия / условия |
|---|---|---|
| RFSD — Russian Financial Statements Database (Bondarkov S., Ledenev V., Skougarevskiy D. Scientific Data, 2025. doi:10.1038/s41597-025-05150-1; https://github.com/irlcode/RFSD) | годовая бухгалтерская отчётность юрлиц за 2017 год: структура балансов для синтетических профилей ЮЛ | CC BY 4.0 |
| Открытые выгрузки ЕГРЮЛ/ЕГРИП — OFData (https://ofdata.ru/open-data) | статус, дата регистрации и ОКВЭД ИП для синтетических профилей | условия использования — на странице источника; требуют сверки перед публикацией |
| Исторический реестр МСП (https://data.rcsi.science/data-catalog/datasets/205/) | категория МСП и ОКВЭД на дату наблюдения | условия использования — на странице источника; требуют сверки перед публикацией |

- НКР, «Кредитование МСП», 13.07.2026 — дефолтность малого (5,9%) и микробизнеса (9,9%) за 12 месяцев: https://www.ratings.ru/analytics/finance/SME-130726/
- Банк России, обзор рынка кредитования МСП за IV кв. 2025 — I кв. 2026 — средние ставки: https://www.cbr.ru/Collection/Collection/File/60978/4q_2025_1q_2026.pdf
- Базельский комитет, Basel III, CRE32 (базовый подход ПВР) — значения LGD.
- Ключевая ставка Банка России — 14% (решение от 23.10.2026).

## 4. Смоделированные интеграции

Ни один внешний сервис в прототипе не вызывается по-настоящему. Все источники заменены мок-сервисом (`mocks/`, порт 8001), который отдаёт синтетические данные из `mocks/companies/*.json` в формате, близком к реальным ответам (`docs/mocks-format.md`).

| Реальный источник | В прототипе | Маршрут мока |
|---|---|---|
| ЕГРЮЛ / ЕГРИП (ФНС) | мок | `GET /egrul/{inn}` |
| ФНС: налоговая задолженность, приостановления операций, реестр МСП | мок | `GET /fns/{inn}` |
| Платформа ЦБ «Знай своего клиента» (ЗСК, 115-ФЗ) | мок | `GET /zsk/{inn}` |
| Бюро кредитных историй | мок | `GET /bki/{inn}` |
| ГИР БО (бухгалтерская отчётность) | мок | `GET /gir-bo/{inn}` |
| Внутренние данные банка: обороты по счёту, кредиты в банке | мок | `GET /bank/{inn}` |
| Авторизация клиента и сотрудника | вход по ИНН, без пароля | — |
| Подписание кодом из SMS | код показывается прямо в кабинете | — |
| Выдача кредита в АБС | смена статуса и график платежей | — |
| Лента новостей банка (alfabank.ru/news/t) | демонстрационные тексты во фронтенде | — |
| Распознавание выписки из другого банка | клиент сам указывает сумму поступлений | — |

Товарные знаки и логотип Альфа-Банка используются только для демонстрации в рамках хакатона.
