# UL: внешний ориентир9,9% для микробизнеса

Отдельный сценарий,25.10.2026. Исходный источник: пользователь сообщил ориентир исследования Полины. Период, событие и сопоставимость с годовой90+PD пока не подтверждены.

Подобран один сдвиг логита на микропредприятиях **калибровочной** части: 2492 строк. Средняя вероятность на ней: 15.338165% → 9.900000%. Тест не использовался для подбора.

Свободный член: -3.543934019527 → -4.399106388545; дополнительный сдвиг: -0.855172369018. Коэффициенты факторов, преобразования, C, входные данные и синтетические метки не менялись. Тот же сдвиг применяется малым предприятиям; отдельного реального ориентира для них нет.

Ранжирование и Gini сохраняются. Средний PD другого набора, включая test, не обязан быть ровно9,9%. Синтетические исходы остались около15,5%; поэтому Brier/logloss/E-O на них отражают несовпадение нового внешнего сценария с прежним симулятором, а не проверку реального9,9% риска.

Метрики test: AUC=0.92883319, Gini=85.766638%. Никакого встроенного порога отказа15% модель не содержит. Такой порог — отдельная кредитная политика.
