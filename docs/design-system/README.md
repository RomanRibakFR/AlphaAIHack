# Дизайн-система Альфа-Банка в нашем проекте

Коротко: мы не копировали CSS с сайта. Альфа-Банк выкладывает свою дизайн-систему
в открытый доступ, мы поставили её как обычную зависимость и добавили сверху
только то, чего в пакете нет, — фирменный шрифт и размеры страницы.

## Что откуда

| Слой | Источник | Где лежит |
| --- | --- | --- |
| Компоненты (кнопки, поля, таблицы, слайдеры…) | `@alfalab/core-components` 50.37.0, MIT, [core-ds/core-components](https://github.com/core-ds/core-components) | `node_modules`, импортируется по частям |
| Токены (цвета, радиусы, отступы, типографика) | `@alfalab/core-components-vars` 11.4.1 | подключён в `src/ui/tokens.css` |
| Шрифт Alfa Interface Sans | CDN Альфа-Банка, `alfabank.servicecdn.ru/media/fonts/` | `public/alfa/fonts/`, объявления в `src/ui/fonts.css` |
| Иллюстрации и логотип | главная alfabank.ru, их же CDN | `public/alfa/img/` (80 файлов), логотип — `src/ui/AlfaLogo.tsx` |
| Размеры страницы и промо-типографика | замеры живой страницы при ширине 1280 | `src/ui/tokens.css` |

Тема в пакете называется **bluetint** — это проверено, а не угадано: все значения,
замеренные на живом alfabank.ru, совпали с её токенами до последнего знака.

| Замерено на сайте | Токен в пакете |
| --- | --- |
| `#ef3124` — красный в логотипе и кнопках | `--color-light-accent-primary` |
| `rgba(3, 3, 6, 0.88)` — основной текст | `--color-light-text-primary` |
| `rgba(255, 255, 255, 0.94)` — текст на тёмном | `--color-light-text-primary-inverted` |
| `rgba(238, 238, 251, 0.55)` — вторичный на тёмном | `--color-light-text-secondary-inverted` |
| `#f2f3f5` — подложка карточек (76 элементов на странице) | `--color-light-base-bg-secondary` |
| `#121213` — шапка и футер | `--color-light-base-bg-primary-inverted` |
| `#ec2d20` / `#0d9336` — ошибка / успех | `--color-light-text-negative` / `-positive` |
| радиусы 64, 32, 24, 10, 99 | `--border-radius-64` и соседи |

## Как подключено

`src/main.tsx` импортирует `src/ui/index.css` — одну точку входа. Она тянет:

1. `fonts.css` — три начертания Alfa Interface Sans (400, 500, 700; других на CDN нет);
2. `tokens.css` — `@import "@alfalab/core-components-vars/index.css"` плюс наши переменные;
3. `base.css` — сброс, шрифт на `body`, утилиты сетки.

Компоненты импортируются по одному, не пакетом целиком:

```tsx
import { Button } from "@alfalab/core-components/button";
import { Input } from "@alfalab/core-components/input";
```

## Шпаргалка по компонентам

Важное отличие версии 50 от того, что пишут в старых примерах:

- `size` у `Button` и `Tag` — **число** (высота в пикселях): `32 | 40 | 48 | 56 | 64 | 72`, не `"s" | "m" | "l"`.
- `view` у `Button`: `accent` (фирменный красный, главный CTA) · `primary` (чёрная) ·
  `secondary` · `outlined` · `transparent` · `text`. Видов `tertiary` и `link` больше нет.
- В шапке alfabank.ru «Войти» — это `view="accent" size={40}`.

Подходящее для кредитного кабинета:

| Задача | Компонент |
| --- | --- |
| Статус заявки | `Status` (`color`: green / orange / red / blue / grey) |
| Сумма кредита | `Amount`, `AmountInput` |
| Сумма и срок ползунками | `Slider` (noUiSlider с подписями-pips) |
| Выбор продукта | `Select`, `Tag` |
| История статусов | `Table`, `Collapse` |
| Шаги конвейера | `Tabs`, `Stepper` |

## Клон главной: что сделано и чего нет

Клон собран как образец вёрстки — из него удобно копировать секции в кабинет.
Размеры сняты с живой страницы: колонка 1140, шаг сетки 24, шапка 104,
белый блок со скруглением 64, карточки продуктов 267×298, промо 364×364,
сервисные плитки 558, карточка калькулятора 1140×470.

**Есть:** шапка, геро-бенто с видео, «Выбирайте лучшее» (3 вкладки, 24 карточки),
«Рассчитайте выгоду» (4 вкладки с живым расчётом), промо-карусель (12 карточек),
блок партнёров, «Сервисы», «О банке» (2 вкладки), умный поиск, футер.

**Нет:**

- **Мегаменю в шапке.** На сайте под каждым пунктом раскрывается панель
  на 89 ссылок. В клоне пункты ведут сразу на alfabank.ru.
- **«Читайте главное об инвестициях»** и **«Пользуйтесь выгодными предложениями
  в наших сервисах»** — эти две секции не переносил.
- **Полная карта сайта в футере** (~250 ссылок). Оставлены четыре колонки
  и юридический текст.
- **Живые данные.** Курсы валют и котировки на сайте приходят с их API.
  В клоне стоят значения, снятые в момент съёмки, — блок не висит пустым,
  но и не обновляется.
- **Мобильная вёрстка.** Её у этой страницы нет: сайт отдаёт
  `<meta name="viewport" content="width=1280">` и на узком экране просто
  масштабирует десктопный макет. Клон повторяет это поведение
  (`useFixedViewport` в `AlfaHome.tsx`). Мобильная версия alfabank.ru живёт
  за отдельной проверкой браузера, её я не трогал.

Расхождение, которое стоит знать: в калькуляторе кредита сайт показывает
платёж 49 500 ₽ при сумме 1 350 000 ₽ на 3 года, а честный аннуитет по их же
ставке 17,99% даёт 48 799 ₽. Разницу сайт не раскрывает — вероятно, страховка
или округление. У нас считается аннуитет, поэтому цифра меняется вместе
со слайдерами.
