# Дизайн-система Альфа-Банка в нашем проекте

Коротко: Альфа-Банк выкладывает свою дизайн-систему в открытый доступ, мы поставили
её как обычную зависимость. Ничего с их сайта не скачивали и не копировали.

## Что используем и на каком основании

| Слой | Источник | Лицензия |
| --- | --- | --- |
| Компоненты (кнопки, поля, слайдеры, таблицы…) | `@alfalab/core-components` 50.37.0, [core-ds/core-components](https://github.com/core-ds/core-components) | MIT |
| Токены: цвета, радиусы, отступы, типографика | `@alfalab/core-components-vars` 11.4.1 | MIT |
| Логотип | инлайновый SVG в `src/ui/AlfaLogo.tsx` | организаторы разрешили логотип и фирменные цвета |
| Шрифт | системный (`system-ui` и запасные) | ничей, ставить нечего |

Тема в пакете называется **bluetint** — её значения совпадают с фирменными цветами банка:

| Цвет | Токен |
| --- | --- |
| `#ef3124` — фирменный красный | `--color-light-accent-primary` |
| `rgba(3, 3, 6, 0.88)` — основной текст | `--color-light-text-primary` |
| `rgba(255, 255, 255, 0.94)` — текст на тёмном | `--color-light-text-primary-inverted` |
| `#f2f3f5` — подложка карточек | `--color-light-base-bg-secondary` |
| `#121213` — шапка и футер | `--color-light-base-bg-primary-inverted` |
| `#ec2d20` / `#0d9336` — ошибка / успех | `--color-light-text-negative` / `-positive` |

## Про шрифт

Фирменный **Alfa Sans сделан на основе коммерческого Graphik**, открытой лицензии
у него нет. Кейс прямо запрещает зависеть от закрытых корпоративных лицензий,
поэтому фирменный шрифт мы не используем: в `--alfa-font` лежит системный стек.

Если понадобится что-то ближе к фирменному начертанию, брать шрифт с открытой
лицензией — например Inter или Golos Text под SIL OFL — и класть файлы в репозиторий.
Шрифт с CDN банка не годится.

## Чего в проекте нет и почему

Клона главной alfabank.ru, их картинок, видео и файлов шрифта здесь нет.
Организаторы разрешили логотип, фирменные цвета и дизайн-систему — копировать
сайт банка и его медиафайлы разрешения не было. Сетку и размеры страницы
мы повторяем по мотивам (колонка 1140, шаг 24, шапка 104, скругления 64/32/24),
это общие приёмы вёрстки, а не чужие файлы.

## Как подключено

`src/main.tsx` импортирует `src/ui/index.css` — одну точку входа. Она тянет:

1. `tokens.css` — `@import "@alfalab/core-components-vars/index.css"` плюс наши переменные;
2. `base.css` — сброс, шрифт на `body`, утилиты сетки;
3. `motion.css` — анимации.

Компоненты импортируются по одному, не пакетом целиком:

```tsx
import { Button } from "@alfalab/core-components/button";
import { Input } from "@alfalab/core-components/input";
```

## Что посмотреть глазами

`/ui-kit` — витрина: палитра, шрифтовая шкала, радиусы, живые компоненты.
Запуск: `npm --prefix frontend run dev`.

## Шпаргалка по компонентам

Важное отличие версии 50 от того, что пишут в старых примерах:

- `size` у `Button` и `Tag` — **число** (высота в пикселях): `32 | 40 | 48 | 56 | 64 | 72`,
  не `"s" | "m" | "l"`.
- `view` у `Button`: `accent` (фирменный красный, главный CTA) · `primary` (чёрная) ·
  `secondary` · `outlined` · `transparent` · `text`. Видов `tertiary` и `link` больше нет.
- `secondary` рассчитан на светлый фон: на тёмной шапке он почти сливается,
  поэтому в лендинге такие кнопки перекрашены классом `.lp-btn-ghost`.

Подходящее для кредитного кабинета:

| Задача | Компонент |
| --- | --- |
| Статус заявки | `Status` (`color`: green / orange / red / blue / grey) |
| Сумма кредита | `Amount`, `AmountInput` |
| Сумма и срок ползунками | `Slider` |
| Выбор продукта | `Select`, `Tag` |
| История статусов | `Table`, `Collapse` |
| Шаги конвейера | `Tabs`, `Stepper` |
